# LeetCode 3880. 两个值之间的最小绝对差值

## 题目描述

[LeetCode 3880. 两个值之间的最小绝对差值](https://leetcode.cn/problems/minimum-absolute-difference-between-two-values/description/)
给你一个只包含 0、1 和 2 的整数数组 nums。

如果 nums[i] == 1 且 nums[j] == 2，则称下标对 (i, j) 为 有效 的。

请返回所有有效下标对中 i 和 j 之间的 最小 绝对差。如果不存在有效下标对，则返回 -1。

下标 i 和 j 之间的绝对差定义为 abs(i - j)。

## 解题思路

- **核心算法**模拟
  遍历每次碰到1或者2就进行比较,前提是当前碰到1过去就要遇到过2,当前碰到2过去就要遇到过1.取最小值

## 代码实现

```c++
class Solution {
public:
    int minAbsoluteDifference(vector<int>& nums) {
        int n = nums.size();
        int a = -1, b = -1;
        int ans = INT_MAX;
        for (int i = 0; i < n; ++i) {
            if (nums[i] == 1) {
                a = i;
                if(b!=-1)
                {
                ans = min(ans, abs(b - a));

                }
            }
            if (nums[i] == 2) {
                b = i;
                if(a != -1 )
                ans = min(ans, abs(b - a));
            }
        }
        return ans == INT_MAX ? -1 : ans;
    }
};
```
